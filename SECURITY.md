# Security policy

Please report security problems privately rather than in a public issue. Use
the "Report a vulnerability" button on this repository's Security tab.

The things I care most about here are anything that could expose a Plex
token, server address or library contents (in logs, URLs, crash output,
network requests or the Discord status), and the updater accepting an update
that isn't signed with the project's key.

This is a one-person project, so I'll reply as soon as I can. Only the latest
release is supported.
