# Code of conduct

Platter is a small project and I'd like it to stay a friendly place to ask
questions, report bugs and send changes.

Be kind and assume good faith. Disagree about code and ideas, not about people.
Keep it on topic, and help newcomers instead of making them feel lost.

Not okay here: harassment, insults or personal attacks, slurs, sexual content,
threats, sharing someone's private information, and pushing on after being
asked to stop. That covers issues, pull requests, Discussions and anywhere else
you're speaking as part of the project.

If something happens that you don't want to raise in public, use the
"Report a vulnerability" button on the Security tab (it's private), or report
the comment or user through GitHub. I'll read every report and keep it private.

I may edit or remove comments, lock threads, or block people who break these
rules. For anything serious I'll act first and explain after.
